# Plan d'implémentation — Agent SOC AgentDoctor

> **Pour l'exécution :** une tâche à la fois, un commit + push après chaque tâche (auteur Rayen Selmen). Cases `- [ ]` pour le suivi.

**But :** un agent IA SOC qui, sur clic, enquête sur des alertes issues de vrais logs SSH (WSL), décide (vrai/faux positif + gravité), agit (bloquer IP, signaler compte, fermer alerte), puis envoie un rapport par email.

**Architecture :** Angular (une page) → FastAPI → outils Python → OpenAI (tools). Détection et scoring en Python ; le LLM ne décide que du triage via les outils. PostgreSQL `AgentDoctor`.

**Stack :** Python 3.13, FastAPI, psycopg v3, openai, pytest ; Angular 18 ; PostgreSQL 17 ; Gmail SMTP.

**Prérequis déjà validés :** PostgreSQL `AgentDoctor` OK, OpenAI `gpt-4o-mini` OK, Gmail SMTP OK, WSL Ubuntu (sshd 2222 + rsyslog + user `victime`) OK, Kali hydra OK, `.env` rempli et ignoré par git.

## Scénarios de démo
1. 1 seul échec → l'agent ferme en **faux positif**, aucune action.
2. Brute-force (hydra) → **vrai positif, high**, IP bloquée (commande générée).
3. Brute-force réussi sur `victime` → **critical**, IP bloquée + compte signalé.
Puis email reçu avec le récapitulatif.
